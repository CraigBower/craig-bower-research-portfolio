# Craig Bower Research Portfolio — starter site

This is a Quarto website starter package for a professional Scientific AI research portfolio.

## What is included

- Home page and research positioning
- Research / Projects / Writing / About pages
- Full HyperFlux flagship case study
- Six HyperFlux figures
- BibTeX references
- Minimal custom styling

## Before publishing publicly

1. Replace the generic GitHub and LinkedIn links in `_quarto.yml` with your own profile URLs.
2. Read the HyperFlux case study once more for project/IP clearance.
3. Remove any project placeholders you do not want visible yet.
4. Keep private evidence/claim-audit files OUTSIDE this public repository.

## Preview locally

Install Quarto, open a terminal in this folder, then run:

    quarto preview

Quarto will build the site and open a local preview in your browser.

## Render the complete site

    quarto render

The generated site will appear in `_site/`.

## Git workflow (once Git is installed)

    git init
    git add .
    git commit -m "Initial research portfolio site"

Then connect the repository to GitHub and publish with GitHub Pages.
